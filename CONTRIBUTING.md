# Contribuer

Merci de ton intérêt !

1. Ouvre une **issue** pour proposer une idée ou signaler un bug (joins le message Telegram ou l'erreur).
2. Pour une pull request : une seule amélioration par PR, des tests hors ligne dans `tests/`
   (aucun appel réseau), et `python -m pytest -q` qui passe.
3. Toute nouvelle stratégie doit citer sa source (étude, article) dans `docs/STRATEGIES.md` et être
   validée par le backtest intégré.
4. Jamais de clé, de jeton ou de donnée de compte dans le code ou les issues.
